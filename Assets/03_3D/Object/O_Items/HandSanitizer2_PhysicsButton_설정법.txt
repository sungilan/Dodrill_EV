================================================================
  Item_HandSanitizer2 — VR 물리 버튼 (PhysicsGadgetButton) 설정법
  기준: Pose Button (AutoHand 예제) 구조 기반
================================================================

[ 현재 최종 적용값 ]

  버튼 Rigidbody
  - Mass              : 2
  - LinearDamping     : 2       ← 복귀 속도 조절 (높을수록 느리게 올라옴)
  - UseGravity        : false
  - IsKinematic       : false   ← 반드시 false (true면 버튼 안 눌림)
  - Constraints       : 122     ← FreezePosition XZ + FreezeRotation XYZ (날아가지 않게)

  ConfigurableJoint
  - XMotion           : Locked (0)
  - YMotion           : Limited (1)   ← 위아래로만 움직임
  - ZMotion           : Locked (0)
  - LinearLimitSpring : spring=0, damper=0   ← 0으로 두면 한계점에서 튕김 없음
  - LinearLimit       : 0.02m         ← 버튼이 눌리는 최대 깊이 (클수록 깊이 들어감)
  - YDrive positionSpring : 150       ← 버튼 복귀 힘 (낮으면 안 올라옴, 높으면 반동)
  - YDrive positionDamper : 35        ← 복귀 시 제동 (낮으면 튕김, 높으면 안 올라옴)

  PhysicsGadgetButton
  - threshold         : 0.2    ← 눌림 인식 기준 (0~1, 낮을수록 살짝만 눌러도 인식)
  - lockOnPressed     : false

  HandSanitizerPump
  - _pressDirection   : (0, -1, 0)    ← Y 아래 방향 (버튼 축과 일치)
  - _pressDepth       : 0.02

  몸통 Rigidbody (dispenser body)
  - IsKinematic       : false  ← true면 버튼 조인트가 동작 안 함
  - Constraints       : 126    ← FreezeAll (위치/회전 전부 고정, 날아가지 않음)

================================================================
[ 튜닝 가이드 ]

  ▶ 버튼이 눌린 후 원위치까지 안 올라올 때
      LinearDamping 줄이기 (2 → 1)
      또는 positionSpring 올리기 (150 → 200)

  ▶ 올라올 때 반동/튀는 현상
      positionDamper 올리기 (35 → 50)
      LinearLimitSpring은 반드시 0 유지

  ▶ 손이 버튼 안으로 너무 깊이 들어갈 때
      LinearLimit 줄이기 (0.02 → 0.015)

  ▶ 버튼 누름이 인식이 안 될 때
      threshold 낮추기 (0.2 → 0.15)
      또는 LinearLimit 올리기 (0.02 → 0.025)

  ▶ 버튼이 살짝만 닿아도 눌릴 때
      threshold 올리기 (0.2 → 0.3)

  ▶ 누르면 몸통이 날아갈 때
      몸통 Rigidbody IsKinematic 확인 (false로 설정 후 Constraints=126)

================================================================
[ 주의사항 ]

  - 몸통 Rigidbody IsKinematic = true 이면 버튼 조인트가 동작하지 않음
    → 반드시 false + Constraints 로 고정
  - FishNet 서버(Host 모드) 미실행 시 ServerRpc가 전달 안 되어
    버튼이 눌려도 애니메이션/완료 처리가 동작하지 않음
  - 버튼 오브젝트 Inspector에서 ConfigurableJoint > YMotion = Limited 확인
    (XMotion이 Limited면 좌우로 움직이는 설정 = 안 눌림)
