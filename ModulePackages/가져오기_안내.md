# DoDrill 모듈 패키지 가져오기 (2026-11-20)

파일: `DoDrill_Modules_Safety_20261120.unitypackage` (약 400MB)

## 들어 있는 것

`Assets/01_Script/` 아래 **Common · Interaction · Avatar · Engine · Ui · Solo · Safety · Lobby** 8개 폴더 전체(스크립트·asmdef·프리팹·씬·아트·Localization 자산·README)와 `Assets/01_Script/README.md`.
모듈이 폴더 밖에서 쓰는 에셋 18개(UI 스프라이트·텍스처·`EventSystem` 프리팹 등)도 원래 경로(`Assets/02_UI`, `Assets/07_Resources`, `Assets/Resources/Thumbnails`, `Assets/ThirtParty/SimpleSpinner`)로 함께 들어 있다.

들어 있지 않은 것: 플러그인·패키지(아래 1단계), EV 콘텐츠(`Content`), 패키지 샘플(XR Hands 손 모델·XRI 스프라이트는 해당 패키지의 샘플을 가져오면 된다).

## 가져오는 순서

> **중요 — FishNet·MasterServerToolkit·AutoHand는 EV가 쓰는 버전(수정본)이 필요하다.** 모듈은 이 셋의 EV 수정본 기준으로 만들어졌다. 에셋스토어/깃허브 최신판을 그대로 설치하면 오류가 난다(예: 최신 MST에는 `MstEventKeys.showLobbyView`·`MatchmakingBehaviour.CreateNewLobby`가 없고, 최신 AutoHand에는 `XrDetect`가 없으며, FishNet은 EV가 4.6.12인데 최신은 4.7.x). EV의 `Assets/Packages/{FishNet,MasterServerToolkit,AutoHand}` 폴더를 그대로 복사해 쓴다(`.meta` 포함, 새 프로젝트의 `Assets/` 바로 아래).
>
1. **새 Unity 6(6000.3.x) + URP 프로젝트**를 만들고 플러그인을 먼저 설치한다: FishNet 4.6, MasterServerToolkit, AutoHand(+FinalIK), DOTween, TextMeshPro, Localization, InputSystem, XR 패키지(management·openxr·hands·interaction toolkit), Newtonsoft Json. Odin은 없어도 된다.
   - **Final IK(에셋스토어)에는 asmdef가 없다.** 모듈의 asmdef가 `RootMotion`을 참조하므로, 설치 후 `FinalIK_asmdef` 폴더의 두 파일을 `Assets/Plugins/RootMotion/RootMotion.Runtime.asmdef`, `Assets/Plugins/RootMotion/Editor/RootMotion.Editor.asmdef`로 복사한다(Final IK가 `Assets/Plugins/RootMotion`에 설치되지 않았다면 그 폴더 위치에 맞춘다). 최신 Final IK의 데모 스크립트는 `UnityEngine.InputSystem`을 쓰므로 이 폴더의 `RootMotion.Runtime.asmdef`에는 `Unity.InputSystem` 참조가 들어 있다(그대로 복사할 것). 이게 없으면 `RootMotion`/`VRIK`/`FingerRig`를 찾을 수 없다는 오류가 계속 난다.
   - **Collections**(`com.unity.collections`)와 **Unity OpenXR: Meta**(`com.unity.xr.meta-openxr`)도 Package Manager에서 설치한다(EV는 2.6.2 / 2.4.0).
2. DOTween 설정(`Tools ▸ Demigiant ▸ DOTween Utility Panel` ▸ Setup DOTween…)에서 **Create ASMDEF**를 눌러 `DOTween.Modules.asmdef`를 만든다. 없으면 `DOFade`·`DOAnchorPos` 등을 찾을 수 없다는 오류가 난다. 직접 만든다면 `Assets/Plugins/Demigiant/DOTween/Modules/DOTween.Modules.asmdef`에 이름 `DOTween.Modules`, 참조 `UnityEngine.UI`·`Unity.TextMeshPro`, `overrideReferences: true`, `precompiledReferences: ["DOTween.dll"]`.
3. 프로젝트 **Tags**에 `HoldPoint`, `Anchor`를 추가하고 레이어(`Hand`, `Grabbing` 등 AutoHand 레이어)를 맞춘다.
4. `Assets ▸ Import Package ▸ Custom Package…`로 이 파일을 가져온다(전체 선택).
5. 컴파일 오류가 없는지 본다.
6. 메뉴로 시작한다.
   - `Tools ▸ DoDrill ▸ 범용 프리팹 만들기`, 이어서 멀티플레이 예제 씬 만들기(예제 폴더 `99_ModuleExample`은 이 패키지에 없다 — 필요하면 따로 가져온다)
   - `Tools ▸ DoDrill ▸ Localization 설치`
   - `Tools ▸ DoDrill ▸ 로비 템플릿 씬 설치`
7. 로비 서버 주소는 설치된 씬의 `ClientToMasterConnector.serverIp`, `SpawnerBehaviour.machineIp`, Tugboat `_clientAddress`를 자기 서버로 바꾼다(템플릿 기본값 `127.0.0.1`).

자세한 내용은 `Assets/01_Script/README.md`와 각 모듈 폴더의 `README.md`.

## 알아둘 점

- 이 폴더(`ModulePackages`)는 용량이 커서 git에 올리지 않는 것을 권한다.
- 패키지에는 EV 문구가 든 `UI_Text` 테이블과 EV 서버 주소가 아닌 로컬 값(`127.0.0.1`)의 템플릿 씬이 들어 있다.
